This repo contains annotation results for the matching algorithm. Annotators were provide with the candidate solution and a list of reference solutions.

They have marked each group on whether it contains any mistakes (OK/Not OK). After that, they have checked the Not OK samples and counted the amount of pairs that the matching made a mistake.

Annotator 1 counted 25 pairs with issues, and Annotator 2 - 21.

Script on calculating the agreement is [check.py](check.py).
